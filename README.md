# 鳄鱼派 · gator-perspective

> 从「像鳄鱼一样思考」日更复盘 **1643 篇 / 474 万字**语料中蒸馏出的 A 股交易思维框架 Skill。
> 让 AI 用这套认知操作系统，而不是背几句金句。

一个**人物视角 Skill**：它不复制这个人说过什么，而是提炼他**怎么想**——用什么镜片看市场、用什么规则做判断、什么条件下会错。

## 用法

```
用鳄鱼派的视角看看今天的行情
鳄鱼派会怎么看这次回调？
如果鱼哥来判仓位，他会怎么做
```

Skill 激活后会先查真实行情数据（走 Agentic Protocol 的五个维度：护盘 / 结构 / 流动性 / 量价情绪 / 外围产业），再用这套框架给**条件式**结论，而不是甩一个单边判断。

## 诚实边界

这个 Skill 主动写明了它做不到什么：

- **流程不是算法**：止跌/上涨流程改版四次，六步版与五步版对同一段行情给过矛盾叙事。它解释过去行，精确预测不行。
- **你看到的交易是筛选过的**：原作者 2024-04 起关闭个股持仓披露，公开的多是指数期货与 ETF。「可以开始试多」≠「已经试多」。
- **有直接自相矛盾**：说「牛市结束之前股指不会去放空」，2026 年 9 月却持有 IM 空单。这些矛盾被保留，没有调和。
- **研报面不是他的声音**：913 篇研报由团队协作产出，语言指纹与复盘差 372 倍，不能当作个人思维证据。
- **时效性**：语料截止 2026-10-21。市场判断有保质期。
- **它是 A 股散户视角的择时者**，不是全天候配置者。
