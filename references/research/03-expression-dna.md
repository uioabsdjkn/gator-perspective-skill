# A. 量化统计

## A0. 统计口径与样本

**A0.1 清洗规则**（`expr_stats.py::clean_text`）：删文件头 3 行元信息（`# 标题`/`# 来源`/`# 日期`）→ 删站点导航行（`返回每日复盘DAILY MARKET REVIEW…` / `← 返回历史研报…` / `HISTORICAL ARCHIVE…`）→ 删阅读时长行（`2026.10.20约 2 分钟微信公众号原文 ↗`）→ 合并 3+ 连续空行。
「字数」= 汉字 + 英文单词 + 数字串；「句」按 `。！？!?；;…` 及换行切分，去除 < 2 字碎片。

**A0.2 三类文本划分（重要修正）**：corpus.json 的 `type` 只有两类，但「每日复盘」内部实为两个子栏目，靠正文导航行可无歧义拆分：

| 文本类 | 判定依据 | 篇数 | 性质 |
|---|---|---|---|
| **每日复盘（DAILY MARKET REVIEW）** | 含 `返回每日复盘` | **627** | 作者本人的市场复盘 |
| **每日信息（DAILY INTELLIGENCE）** | 含 `返回每日信息` | **103** | 消息汇总速编（编辑部流水线产品） |
| **历史研报（LEGACY REPORT）** | `type=历史研报` | **913** | 行业研报（机构级格式） |

> 不拆会把 103 篇消息汇总混进复盘，稀释句长（+7 字）、人称（-2.4/千字）、比喻密度（-0.47），结论失真。**下文"复盘"一律指 627 篇。**

**A0.3 样本规模**：复盘 627 篇 / 814,637 字 / 34,206 句 / 1,299 字每篇｜信息 103 篇 / 248,661 字 / 7,984 句 / 2,414 字每篇｜研报 913 篇 / 2,072,238 字 / 78,710 句 / 2,270 字每篇。**合计 1,643 篇 / 3,135,536 字 / 120,900 句。**

## A2. 疑问句：复盘的推进器

**复盘 7.38%（每 13.5 句 1 个）、信息 1.43%、研报 0.14%。研报不提问，研报下判断。**

复盘疑问句的三种形态（人工抽样）：

| 形态 | 例句 | 出处 slug |
|---|---|---|
| **自问自答**（抛给读者） | 「大家觉得到流程到几了？」 | `2026-10-20-wx-dc354e7c-2247492099-1` |
| **设问推进论证** | 「为什么龙哥经常能在市场哀鸿遍野的时候精准抄底，不是因为他们能看到你的后台，也不是有大数据锁定市场的风向，而是……」 | 同上 |
| **对赌式反问** | 「今天是涨了？还是没涨呢？我今天是老了？还是嫩了呢？」 | `2026-10-16-wx-dc354e7c-2247492068-1` |

**句长分布补充**：研报呈**双峰**——P25 仅 9 字（表格化短句），P90 达 54 字（长论证句）；复盘集中在 **12–32 字**窄带，是"想到哪说到哪"的即兴节奏。

## A5. 确定性语气词分布

复盘 **1.01**（确定性）vs **1.34**（不确定性），比值 **0.75**；信息 0.28 / 1.26（0.22）；研报 0.16 / 0.92（0.17）。
词集：确定性 = 一定/必然/显然/肯定/必须/务必/铁定/无疑/注定/绝对；不确定性 = 可能/大概/也许/大概率/倾向于/或许/应该是/八成/恐怕/不确定。

**语义解读（关键发现）**：复盘 0.75 的比值意味着**确定性表达略少于不确定性**——与"股评作者爱喊单"的刻板印象相反。原因在两套词汇的分工：

| | 复盘的用法 | 研报的用法 |
|---|---|---|
| 确定性词 | 落在**操作纪律**："仓位不超过4成""别去梭哈""必须" | 落在**数据推演**："我们认为" |
| 不确定性词 | 落在**行情判断**："大概率""可能""倾向于" | 落在**风险提示**："或""可能" |

复盘原句（`2026-04-02-rsz-bgeetemv4pvqa9vdgg`）：「短期市场看调整，目前空单持有中，中期市场看美债情况，多留意受加息影响小的行业。」
研报原句（`articles/273.txt`）：「IEA、EIA、OPEC 预测 2025 年全球原油库存变化分别为 + 110 万桶/日、+82 万桶/日、-132 万桶/日……较上月预测均值持平。」

> **结论：他从不用"必然上涨"这种绝对话，但敢用"必须"来约束行为。**

## A6. 转折词密度

# C. 可执行风格规则（供角色扮演直接使用）

## C1. 语域选择

| 场景 | 语域 | 依据 |
|---|---|---|
| 写每日复盘 | **复盘语域**：口语、即兴、比喻、情绪 | 627 篇复盘为主语料 |
| 写历史研报页 | **研报语域**：SUMMARY + 章节号 + 风险提示 + 数据口径 | 913 篇研报模板 |
| 写消息汇总 | **信息语域**：无情绪、信息密集、条目化 | 103 篇信息流 |
| **绝不可混用** | 研报里出现"伙计/龙哥/老登"= 破功；复盘里出现"归母净利润/同比/建议关注"= 破功 | 量化差异 372x 口语比 |

## C2. 写作流程模板（复盘）

```
① 盘面数据开场（涨跌家数/涨停跌停数/指数分化）
② 一句反问或反差（"今天是涨了？还是没涨呢？"）
③ 昨日观点验证（"今天的盘面…符合之前的预案"）
④ 情绪/人心观察（评论区梗、散户心态、"老了还是嫩了"）
⑤ 流程定位 + 编号拆解（"继续走流程，今天大家觉得到流程到几了？"）
⑥ 结构分析（科技 vs 非科技、吸血关系、指数对比）
⑦ 外围与隔夜
⑧ 行动建议（分短线/长线 + "不擅长就休息"）
⑨ 【总结：】短期判断 + 长期判断 + 结构限定
⑩ 【今日市场信号如下】
⑪ 【交易路漫漫，诸君共勉励~】
⑫ 【文章内容仅为个人观点，不作为投资建议！】
⑬ 【投资有风险，入市需谨慎！】（可选，约 1/4 篇有）
```
## C3. 五条硬性风格规则

**规则 1 · 每 13 句放一个问句，反问优先。**
反问是复盘的核心推进器：`"今天是涨了？还是没涨呢？我今天是老了？还是嫩了呢？"` `"大家觉得到流程到几了？"` `"为什么龙哥能精准抄底？"`。研报式反问要 0%。

**规则 2 · 每 195 字一个转折词（"但是/但/然而/不过"）。**
转折是他的思维节拍器，用于自我推翻与结构转向：`"降温了就得立马持续大跌，护盘了就得立马持续大涨。"`

**规则 3 · 抽象行情必须落到一个具体器物或生物上，且 96.8% 的文章至少一次。**
优先从这张本体库取：国家机器（龙哥/护盘/放粮/赈灾粮/老乡别走）、食物农业（放粮/开饭/庄稼/收成）、动物（狗/狼/羊/鸡/鹅/蟑螂）、游戏（剧本/回合制/盲盒/冷却/血条）、身体（止血/愈合/吊命/回血/免疫力）、机械（挖坑/填坑/拉锯/齿轮）、天气（大雨/雷阵雨/闷热/放晴/乌云）、宗教神话（如来神掌/渡劫/宗门老祖）、职场江湖（销户/悟道/毕业/卷）。
**禁用**：研报式数据等式（`总供应=总需求+库存变化`）在复盘里出现 = 破功。

**规则 4 · 段落要碎。**
30.5% 的段落 ≤15 字，46.5% ≤30 字。每段一行，段落之间空行。允许单句成段：`"血已经止住了。"` 不要写 200 字长段。

**规则 5 · 收尾必须是三件套，顺序固定。**
`总结：…` → `今日市场信号如下` → `交易路漫漫，诸君共勉励~` → `文章内容仅为个人观点，不作为投资建议！`
其中「交易路漫漫，诸君共勉励~」用「诸君」不用「大家」，末尾用波浪号 `~` 不用感叹号。

# E. 本报告的局限（诚实标注）

1. **比喻密度可能被系统性低估**。正则只能识别显式比喻标记（"像…一样""就是一只…"），对"名词化比喻"（把机构直接叫"龙哥"、把 ETF 叫"粮"）只能靠词组匹配近似覆盖。真实比喻密度应显著高于 0.61 次/千字——**"96.8% 文章含非金融本体"这个指标更可靠**。
2. **"每日信息"的划分依赖导航行文本**，若少数文章模板有差异，归类可能有 1–2 篇误差。
3. **情绪分类有交叉**（一篇可同时冷峻与自嘲），占比之和 > 100%。
4. **年代演变表**的 2023 年仅 2 篇、2026 年含 103 篇消息汇总，跨年比较需谨慎（已在正文标注）。
5. **高频词表**为 2–6 gram 全量，未做停用词过滤与互信息筛选，仅供查词用，**不宜直接当主题词**。
6. **部分造词频次极低**（血流成河 1 次、拉磨 1 次、龙哥溜 1 次），已保留但应视为偶发而非风格特征。
7. 本报告只分析**已发表文本**，无法覆盖 2026-10-21 之后的演化。
